Проекты разработчиков

Три проекта, которые сделали наши разработчики. У каждого проекта указано, кто работал над ним и какие технологии использовались.

АльфаМагазин

Описание: интернет-магазин электроники. Есть каталог с фильтрами и поиском, корзина, личный кабинет и оплата онлайн.

Год: 2025

Технологии: HTML, CSS, JavaScript, PHP

Разработчик: Павел Астахов (frontend)

МедЗапись

Описание: сервис записи к врачу в клинику. Пациент может выбрать врача и время, получить напоминание и посмотреть историю визитов.

Год: 2025

Технологии: React, Node.js, PostgreSQL

Разработчик: Егор Куралёнок (full-stack)

ГрафикПлюс

Описание: сервис расписания занятий для учебных заведений. Можно фильтровать расписание по группе и преподавателю и скачать его в PDF.

Год: 2026

Технологии: HTML, CSS, JavaScript

Разработчик: Константин Карловский (frontend)

О проектах

Над каждым проектом работала команда из 2–4 человек: дизайнер, frontend-разработчик, backend-разработчик и тестировщик. Работа шла по этапам: прототип, дизайн, вёрстка, программирование и тестирование. На каждый проект даётся гарантия 3 месяца.
